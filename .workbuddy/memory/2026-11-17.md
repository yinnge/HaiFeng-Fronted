## deploy 卡死排查与优化
- **现象**：push 后 GitHub Actions 第一个 scp（user）卡 29~30 分钟才完成，第二个（admin）秒完；服务器配置未动、之前一直成功。
- **根因**：`appleboy/scp-action@v0.1.4`（老版 drone-scp）在跨境链路抖动时 SFTP 单通道僵死，`timeout`/`command_timeout` 参数对该版本传输阶段不生效，只能等 GitHub 6h 全局超时。第二个包小（5.4M）所以没暴露。
- **改动** `.github/workflows/deploy.yml`：两处 scp `v0.1.4 → @v1`，各加 `timeout: 10m` + `command_timeout: 30m`（v1 才真正覆盖传输阶段）。
- **验证**：改完尚未 push，待下次部署观察。

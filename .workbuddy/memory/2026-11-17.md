### 追加：单图/多图误判（真 bug，同轮修复）
- **现象**：用户截图「头像」栏竟出现多图的 `+ / 添加` 方块，而非单图占位。
- **根因**：`withDefaults` 给了 `modelValues: () => []` 默认值 → `Array.isArray(props.modelValues)` 恒 true → **三处单图（规划师头像 / 两处二维码）全部被当成多图**，上传/链接只会 emit `update:modelValues`，父组件的 `avatarUrl` / `wechatQrcodeUrl` 根本不会写入。
- **修复**：去掉 `modelValues` 默认值，`isMulti = props.modelValues !== undefined`；模板/脚本统一用 `list = computed(() => props.modelValues ?? [])`。
- **居中**：`.iu-multi-add` 与 `:deep(.el-upload)` 都补 `display:flex; align-items:center; justify-content:center`，「+ / 添加」锁在虚线方块正中。
- **上传/链接存哪**：两者最终都只把 URL 字符串存 DB。区别 = 字节由谁托管：「上传」→ `POST /api/v1/admin/common/upload` → `OssService.uploadPublicBytes()` 写到公共读 bucket `haifeng-public`（key `haifeng/images/<uuid>.<ext>`），返回完整 URL；「链接」→ 不传文件，只保存用户粘贴的 `http(s)://` 或 `/` 开头地址，文件需自行托管。均**不写本地静态盘**；私有 bucket `haifeng1` 只用于 VIP 文件门禁，与此无关。
- 验证：`pnpm --filter @haifeng/admin typecheck` 通过。

## 个人中心头像上传（C 端自制头像）
- **需求**：AvatarSelector 支持上传头像到 OSS；新 bucket `haifeng-memeber-svg`（独立公共读）；换头像删旧更细；保留 8 个静态头像；切到静态不删上传头像、可切回。
- **方案关键**：**按 memberId 固定 objectKey**（`haifeng/avatars/{memberId}`，无扩展名、Content-Type 写元数据）→ 覆盖上传天然实现「删旧更新」，且 URL 稳定，切回只需复用 URL，**零 DB 字段 / 零 Flyway 迁移**。
- **保留机制**：上传走新接口 `POST /api/v1/app/member/profile/avatar/upload`（`ProfileController` → `ProfileServiceImpl`）；选静态/切回走既有 `PUT /avatar`（只改 DB avatar，不碰 OSS）。`GET /member/info` 的 `MemberInfoVO` 新增 `customAvatar`：用 `ossService.memberAvatarExists()`（OSS `doesObjectExist`）探测固定 key，未配置 bucket 时 catch `IllegalStateException` 返回 null。
- **校验**：JPG/PNG（禁 SVG 防存储型 XSS）、≤2MB、边长 64~2048px、宽高比 0.5~2；`ImageIO.read` 同时做格式嗅探（扩展名伪装无效）；前端仅先验类型/大小，像素由后端权威判定。dev yml 补 multipart 3MB/4MB。
- **配置**：`OssProperties` 加 `avatarBucketName`/`avatarUrlPrefix`（oss.avatar-*）；`.env` + `deploy/.env.server.example` + `docker-compose.prod.yml`（admin/app 双服务）加 `OSS_AVATAR_BUCKET_NAME` / `OSS_AVATAR_URL_PREFIX`。
- **前端**：`api/member/info.ts` 加 `uploadAvatar(file)`（FormData + multipart，120s）；`AvatarSelector.vue` 网格首格「上传头像」（本地 blob 预览 + 右上角勾选）、第二格「我的头像」（存在 customAvatar 时）、后跟 8 静态；`watch(visible)` 每次打开重置选择、`onBeforeUnmount` revokeObjectURL。
- **验证**：`pnpm --filter @haifeng/user typecheck` 通过；Java 由用户本地编译 + 重启（沙箱禁跑 mvn）；需确认 `haifeng-memeber-svg` bucket 已建且公共读、AK 有写权限。

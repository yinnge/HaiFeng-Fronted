## admin 城市模块：切 tab 丢编辑的 bug 修复
- 文件：`apps/admin/src/views/city/list/index.vue`
- 现象：对话框有「基本信息 / 详细信息」两个 tab。改了基本信息后未保存就切到详情 tab 再点「确定」，只有详情被提交，基本信息改动被静默丢弃。
- 根因：`handleSubmit` 按 `activeTab` 只调 `handleSubmitBasic` 或 `handleSubmitDetail` 其一，关闭弹窗——切 tab 后 activeTab 变了，basic 的编辑（仍存在于 v-model 绑定的 formData）不再被提交。
- 修复：拆出 `saveBasic()` / `saveDetail()`（无 toast、返回 boolean）；`handleSubmit` 在「新增」先 saveBasic 拿 id 再 saveDetail，在「修改」里 saveBasic + saveDetail 一起提交，**与当前停在哪个 tab 无关**，统一弹一次「保存成功」。表单数据因 v-model 绑定在 tab 切换间不丢失，故只要点保存就保存全部改动。
- 校验：admin `vue-tsc --noEmit` 中本文件 0 错误（仅有的 2 个错误在无关文件 algorithm/constraint/dict/index.vue，预存、非本次引入）。`handleSubmitBasic/Detail` 仅存的引用在未被引用的备份 `_fixed.vue`。

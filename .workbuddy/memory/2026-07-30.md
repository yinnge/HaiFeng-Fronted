## user 端个人中心弹窗抖动修复
- 问题：http://localhost:3001/profile 任意弹窗（头像选择 AvatarSelector、消息通知详情等）打开时右侧滚动条消失、页面左右抖动。
- 根因：user 端 `apps/user/src/assets/styles/index.css` 已有 `html,body{ scrollbar-gutter: stable }` 预留位置，但 Element Plus `useLockscreen` 弹窗打开时内联设 `body.style.width = calc(100% - 滚动条宽)`，与 gutter 重复计算 → body 多缩一段 → 抖动。
- 改动：`apps/user/src/assets/styles/index.css` 增加 `body.el-popup-parent--hidden { width:100% !important; overflow:hidden }` 覆盖内联收缩。gutter 已留位置，body 不再缩，抖动消除。
- 对比：admin 端 `apps/admin/src/assets/styles/index.css` 用的是 `.el-popup-parent--hidden{ overflow:scroll !important }`（常驻滚动条轨道 hack），未统一，待用户决定是否对齐。
- 验证：需浏览器实测（工具无法观测布局抖动）。已告知用户刷新 localhost:3001 复测。

## admin dashboard「实体数据对比」空白排查
- 用户疑问：http://localhost:3000/dashboard 的「实体数据对比」柱状图没数据，疑后端未实现。
- 结论：前后端均已实现，非未实现。
  - 后端：DashboardController.getStats()→getDashboardStats()；DashboardServiceImpl.getEntityStats()（DashboardServiceImpl.java:223-238）对 university/major/industry/enterprise/admissionGroup/admissionMajorScore 共 6 表做 selectCount；VO DashboardStatsVO.entityStats 字段齐全。
  - 前端：fetchStats() 拉 /stats → buildStatCards() 读 entityStats → renderEntityCompareChart() 用 G2Plot Column 渲染（index.vue:271-323）。与另两个折线图同容器同 CSS，仅图表类型不同，配置无语法错误。
- 最可能原因：6 张实体表在开发库无数据 → 统计全 0 → 柱子高度 0 看似空白（用户/订单表有数据所以其余卡片有值）。
- 用户回传真实响应：entityStats={universityCount:1, majorCount:1, industryCount:1, 其余0}，证明**有数据**，排除空库假设 → 锁定为前端 G2Plot 渲染问题。
- 第一次修复（❌判断有误，未解决）：当时误判为容器高度 0 + G2Plot 默认 autoFit=false，给三图表加 `autoFit:true`。用户刷新后仍空白 → 该判断错误。
- 二次排查——真正的根因（✅已修复）：渲染时序与 v-if 冲突。bento-grid 容器 `v-if="!loading && stats"`（index.vue:394），而 `loading` 在 fetchStats() 的 `finally` 才置 false；实体图却在 fetchStats 内部、loading 仍为 true 时就 `renderEntityCompareChart()`（原 index.vue:54-55），此时 v-if 为 false、实体图表容器未挂载 → `entityCompareRef.value` 为 undefined → 函数首行 `if (!entityCompareRef.value) return` 直接返回，图表实例从未创建。折线图正常是因为它们在 fetchTrends()（onMounted）渲染，彼时 finally 已执行、loading=false、容器已挂载。
- 修复：把实体图渲染从 fetchStats 内移到 onMounted 末尾（`await Promise.all([fetchStats, fetchOverview]); await fetchTrends(); await nextTick(); renderEntityCompareChart()`），与折线图同一起跑线（loading 已 false、DOM 已挂载、ref 有值）。另将 G2Plot 的 `seriesField:'type'`+`color:数组` 改为 `color:(datum)=>datum.color` 回调（data 增加 color 字段），规避 xField/seriesField 同字段的潜在怪异，每柱固定色。
- typecheck：dashboard 无新增错误；存量错误在 employment/welfare、system/log、user/list（与本次无关）。
- 验证：刷新 localhost:3000/dashboard，实体对比应出现彩条（院校/专业/行业值=1 出条；企业/录取组/分数记录值=0 无条）。

# 2026-07-31 工作日志

## dashboard 系统信息：版本取 pom + AI 配置 null 根因修复
- 需求：① 应用版本改为读取 pom 版本（非硬编码）；② 排查前端「系统信息」aiProvider/aiModel 为 null。
- 后端改动（haifeng-admin）：
  - `pom.xml`：给 `spring-boot-maven-plugin` 增加 `<executions><execution><goals><goal>build-info</goal></goals></execution></executions>`。
  - `DashboardServiceImpl.java`：新增 `import org.springframework.boot.info.BuildProperties` / `org.springframework.beans.factory.ObjectProvider`；字段 `private final ObjectProvider<BuildProperties> buildPropertiesProvider`；`getSystemInfo()` 改为 `info.setAppVersion(bp != null ? bp.getVersion() : "1.0.0")`。用 ObjectProvider 兜底，未 build-info 时不启动失败。
- 结论（回答用户疑问）：**没有其它 flyway 给 system_settings 加 AI 字段**；`provider_name`/`model_name` 自 V2 建表就在，`V33__add_dashboard_and_order_status.sql` 只加了 `total_amount`。dashboard 读的是 system_settings 的「当前选中」指针，而 V24 的 `t_model_provider` 只是服务商**目录**。
- null 根因：前端此前根本没调用 `updateProviderModel`（api 定义了但 0 调用点），所以目录配了、指针仍是 null。
- 前端改动：`apps/admin/src/views/system/settings/components/ProviderCard.vue`：
  - 导入 `updateProviderModel, getSystemSettings`；新增 `currentProviderName/currentModelName` + `fetchCurrent()`（onMounted 调用）；
  - 新增 `handleSetActive(row)` 调 `updateProviderModel`；操作列加「设为当前」按钮（仅启用且非当前时显示）；服务商列给当前行打「当前」徽标；宽度 160→230；补 `.action-active`/`.current-tag`/`.provider-name` 样式。
- 验证：admin `typecheck` 通过，本任务改动无新增错误（存量错误在 employment/welfare、system/log、user/list）。后端 Java 未单独编译（环境无 maven 实测），逻辑已核对。
- 用户侧操作：需在「系统设置 → 服务商」里对想要的那条点「设为当前模型」，dashboard 系统信息才会显示服务商/模型。

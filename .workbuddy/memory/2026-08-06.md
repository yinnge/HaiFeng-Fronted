## admin 侧边栏按权限隐藏无权限模块（permission 需求）
- 需求：管理员无某模块权限时，左侧导航栏不再展示该模块（原先全部展示、点了才报 403/404）。
- 现状：数据链路本来就通——登录 `useAuth.handleLoginSuccess` 已 `fetchProfile()`；后端 `ProfileServiceImpl.getProfile` 用 `SysAdminMapper.selectModuleCodesByAdminId`（sys_admin→sys_role_module→sys_module 三表联查）返回 `moduleCodes`；路由 meta 都带 `moduleCode`；Sidebar `buildMenu` 也有过滤逻辑。**真正的 bug 在两处**：
  1. `Sidebar.vue buildMenu`：父级路由自身无 moduleCode（纯分组，如「就业管理」），子项全被权限过滤后仍 `return item`（children 为空）→ 父级渲染成可点击的橙色空叶子，点击跳 redirect → 403。修法：`visibleChildren.length === 0` 时 `return null`，整个父级隐藏（含三级嵌套自动递归剪枝）。

## 高考算法模块：全局逻辑删除干扰修复（2026-08-06）

### 根因
后端 `application-dev/prod.yml` 配置了全局 `logic-delete-field: isDeleted`，导致所有有 `isDeleted` 字段的实体（不管有无 `@TableLogic`），MP 内置方法（`selectOne`/`updateById`）都会自动：
- SELECT 追加 `AND is_deleted=false`
- UPDATE 追加 `AND is_deleted=false` 到 WHERE，且从 SET 排除 `is_deleted`

**问题2+3+4：专业组列表默认筛选 + 文案**

## 导出 xlsx 二次修复：responseType=blob 被响应拦截器当成业务错误
- 症状：generate 200 正常返回 downloadUrl/fileName；download 接口 200 但响应体是二进制；前端 console 报 `[API Error] undefined: 请求失败`（request.ts 成功拦截器分支）。
- 根因：上一轮只加了 `transformResponse: [(data)=>data]` 绕过 JSON 解析，但 `packages/shared/src/utils/request.ts` 的**响应成功拦截器**仍对所有响应执行 `Number(data.code) !== 200` 判断。blob 响应的 data 是 Blob，`data.code` 为 undefined → `NaN !== 200` → 走"业务错误"分支 reject('请求失败')，blob 永远到不了调用方。
- 修复（request.ts 成功拦截器入口）：`if (config.responseType === 'blob' || config.responseType === 'arraybuffer') return response` —— 二进制响应跳过业务码检查原样返回。
- 排查确认：全项目仅 `apps/user/src/api/wish-plan/index.ts` 的 downloadExport 用 responseType:'blob'，无其他受害者。
- 验证：user vue-tsc 无新错误（仅剩 PlanDetail 3 个存量）；3001 dev server 编译 request.ts 200。
- 经验：全局 axios 实例做响应拦截器时，凡是有二进制下载（blob/arraybuffer），拦截器必须先按 config.responseType 放行，否则 data.code 取 undefined 被误判业务失败。

## 用户端导航栏响应式改造（apps/user/src/components/AppHeader.vue）
- 病根：原导航只有两态（<768px 抽屉 / ≥768px 整行 12 个菜单），768~1100px 小屏直接溢出；字号写死、无容器上限导致大屏拉伸。
- 方案 A 动态溢出折叠：JS 测量 `.desktop-nav` 可用宽度，排不下的菜单收进「更多 ▾」下拉（ResizeObserver + window resize 复测）。
- 大屏阈值 `ENABLE_OVERFLOW_WIDTH = 1500`：≥1500px（覆盖 24 寸/1920 及以上）永远显示完整原始导航，不折叠；<1500px 才按需折叠成「更多」。用户明确：24 寸不要更多，小屏才用更多。
- 就业信息专栏（employment）改为：悬停时在其下方滑出二级 tab 条（从右滑入动画，Transform translateX(40px)），三个子项作为药丸 tab；不再用原下拉。其他有子项的菜单（志愿填报/专业查询/竞赛证书）保留 dropdown。
- 通用补丁：`.app-header-inner` 加 `max-width:1440px; margin:0 auto` 防止超宽拉伸；导航字号/间距用 `clamp()` 流式缩放。
- 验证：`vue-tsc` 类型检查通过；Vite dev（:3001）编译 AppHeader.vue 返回 200 无模板错误。用户要求不再截图。

### 补一次：24 寸大屏 nav 重叠
- 用户反馈截图：24 寸桌面大屏（≥1920）菜单严重重叠压到 logo；笔记本（小屏）反而正常。
- 病根：之前加的 `max-width: 1440px` 想防超宽拉伸，结果把 24 寸可用空间压窄到装不下 12 个一级菜单，flex 居中溢出回弹压到 logo。
- 修复：`max-width: 1440px` → `1600px`（同时给 `.subnav-inner` 同步），让 24 寸放得下，27"+ 也不会过度拉伸。
- 经验：`max-width` 不是越大越好，也不是越小越好——要看 12 个一级菜单需要的最小可用宽度（含 logo + actions + padding）。给用户端这种横向 nav，1600 是安全值。
- 同时把就业二级 tab 样式（`.subnav-tab`）改成跟 `.nav-link` 完全一致：去掉药丸底，去掉橙色背景/边框，改为透明底 + hover 橙色文字 + 橙色下划线。用户要求「跟其他按钮展示的一致」。

### 第三轮：没动 logo / actions → nav 还是吃两边
- 用户反馈：max-width 1600 + threshold 1500 后，24 寸 nav 还是挤到 logo 和 actions 上。
- 数字算账：12 个一级菜单实测 ~1306px；加上 logo（~174）+ actions（~97）+ padding（~88）+ inner gap（~16）≈ 375px 固定开销；inner 至少需要 ~1680 才能装下。
- 修复：
  - `max-width: 1600px` → `1800px`（`.app-header-inner` 和 `.subnav-inner` 同步）
  - `ENABLE_OVERFLOW_WIDTH: 1500` → `1700`（覆盖 24 寸 / 1920 + 20px 安全余量）
- 教训：阈值≠越大越好，要算 nav 实际内容宽度 + 两侧固定开销。当 max-width 抬高时，阈值要同步抬高，否则两端会被压缩。

### 第四轮：就业重构 + 三级 flyout + max-width 再收 100px
- 用户反馈就业二级 tab 条做错了——应该像专业查询那样是**纵向下拉列**，不是整行横向 tab。
- 修复：
  - 删掉 `subnav-bar` 整套（template + CSS + script 状态），就业恢复走通用 `v-else` 下拉分支。
  - `max-width: 2100px` → `2200px`（左再收 100px）。
  - 所有 `dropdown-item` 字体放大加粗：`font-size: 0.8125rem → 0.9375rem`、`font-weight: 500 → 600`。
  - 768~1700px「更多」面板内的就业：新增三级 flyout 面板——点击就业行触发 `expandedOverflowId`，右侧飞入 `flyout-panel`（`left: calc(100% + 4px)`，`flyout-slide` 动画从右滑入），三个子项纵向列出。
  - 更多面板关闭时自动重置 `expandedOverflowId`（watch openDropdownId）。
  - `justify-content: center → space-between` 保留（消除两侧真空）。

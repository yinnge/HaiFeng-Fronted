### 说明
1. 接口已对接过，复用即可。

### 注意事项：
- 避坑一：点击院校卡片直接跳转到院校详情页面。专业，城市，竞赛证书，企业行业同理。不设额外查看详情按钮。
- 避坑二：绝对不要把 5 个模块做成“连续 5 行一模一样的卡片网格”问题：如果 5 个模块全部从上到下平铺成 4 列或 6 列卡片，用户往下滚屏时会看到近 30 张结构雷同的方块，产生严重的视觉疲劳。   专业库（高密度）：采用 3 列 × 2 行 紧凑型数据卡。城市库（横向指标带）：采用 4 列 × 1 行 城市画像卡，顶部带收录总数徽标。竞赛证书 + 企业行业（双栏并排工作台）：这两个模块体量相近且都有双 Tab，直接将它们改造成 左 6 列 + 右 6 列的并排双子星容器！一下子把页面纵向长度缩短 30%，彻底打破单调的水平堆叠。
- 避坑三：卡片底部有“院校详情”和“适应指南”两个独立入口，因此必须保留双按钮；但专业、城市、竞赛、企业卡片只有一个详情跳转，如果每张小卡底部都塞一个 [ 查看详情 ] 按钮，一屏会出现二十多个橙色按钮，喧宾夺主。此外，标题前缀使用 🧰 📚 🎓 🔥 等 Emoji 会拉低专业度，且他给出的 CSS 里使用了早已被淘汰的 float: right。   高定解法：除院校库保留双按钮外，其余 4 个模块采用整卡热区跳转 + 右上角微缩内嵌圆圈箭头 ↗。Hover 时整张卡片微抬升、右上角圆圈变橙色并斜向滑动，干净利落。
- 避坑四：竞赛与证书， 展示完数据后，在下面添加两个按钮：[ 查看全部竞赛 (↗) ][ 查看全部证书 (↗) ];企业行业同理。


## 一、统一决策原则

| 判断标准 | 处理方式 |
|---|---|
| 分类本身是**平行的两种数据类型**（如本科专业/考研专业，都是"专业"但类型不同） | 在百宝箱模块内用 **Tab切换** 展示，每个tab展示 `sort_order` 最高的6-8条，底部统一一个"查看全部"跳转到列表页（列表页内再做类型筛选） |
| 分类是**同一实体下的功能工具/数据维度**（如某大学的"录取数据""可报考考研专业"都是依附于"这所大学"存在的） | **不在百宝箱出现**，而是作为 `/university/:id` 详情页内部的功能Tab，百宝箱只做"导向大学"的入口 |
| 没有自然二分类 | 直接平铺展示 `sort_order` 最高的几条，右上角"查看全部" |

## 二、逐模块拍板结论

### 1️⃣ 院校库 — 你的第二种想法是对的

**结论：百宝箱不要"大学近几年录取数据""可报考考研专业"这两个小标题，它们应该下沉到 `/university/:id` 详情页内部作为功能Tab。**

原因：这两个东西依附于"某一所具体大学"，不是一个独立的列表分类，用户点进去必然要先选学校，所以百宝箱层面只需要做好"学校卡片列表"这一件事，把人导向具体学校即可。

**百宝箱内展示**：直接列出 `sort_order` 最高的 6-8 所学校卡片（就是你截图这种样式），右上角"查看全部 →" 跳转 `/university`。

**路由规划**：
```
百宝箱 "院校库"模块
  ├─ 卡片点击"院校详情" → /university/:id (内部含"录取数据"+"考研专业"两个Tab)
  ├─ 卡片点击"适应指南" → /university/:id/guide
  └─ 右上角"查看全部"   → /university (完整列表+筛选+对比工具)
```

---

### 2️⃣ 专业库 — 用Tab + 平铺Top N

本科专业/考研专业是**平行的两种专业类型**，不依附于其他实体，适合用Tab。

```
百宝箱内：
  [本科专业] [考研专业]  ← Tab切换
  展示该Tab下 sort_order 最高的 6 条
  底部"查看全部" → /major?type=undergraduate（或graduate）
```

跳转到 `/major` 大列表页后，里面再做本科/考研的筛选器即可，不需要做成两个独立页面。

---

### 3️⃣ 城市库 — 按你的想法，平铺+计数

```
不设小标题，直接展示 sort_order 最高的 4-6 个城市卡片
标题行右侧显示："共收录 326 个城市" + [查看全部 →]
查看全部 → /city（完整城市列表+筛选+对比）
```

---

### 4️⃣ 竞赛证书 — 同专业库逻辑，用Tab

```
[竞赛] [证书]  ← Tab切换
查看全部 → /contest-cert?type=contest（或certificate）
```

---

### 5️⃣ 企业行业 — 同专业库逻辑，用Tab

```
[企业] [行业]  ← Tab切换
查看全部 → /enterprise?type=company（或industry）
```

| 左侧头像区 | `logo`（可为空） | 64×64圆角矩形；有logo显示图片；无logo显示浅灰底`#F5F5F5`+校名首字（灰色`#999`） |

## 七、一个额外建议

5个模块全部平铺在首页会比较长，建议：
1. 顶部导航点击"百宝箱"后，页面**平滑滚动**到对应锚点（而非跳转新页）
2. 每个模块区块加一个**浅色背景区分**（比如院校库浅橙背景、专业库浅蓝背景...），或者用左侧色条区分模块，避免5个模块连续堆叠时视觉上分不清边界
3. Tab切换时卡片内容用**淡入淡出动画**（200ms），避免生硬跳变

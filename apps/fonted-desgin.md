# 任务：重构 User 端首页 Hero 区（仅 Hero，不动其他区块）

## 0. 角色与总目标

你是资深 Vue 3 + TypeScript 前端工程师，同时精通视觉设计与动效。
请重构 User 端首页顶部 Hero：由「居中 Logo + 标题 + 描述」改为「左：价值主张 + 搜索 + 引导；右：罗盘式专栏导航」的双栏精致首屏。

设计目标：好看、稳重可信、亲和，主题是「无论你在哪个阶段，都有下一步的答案」。

技术栈（不得新增除 lucide-vue-next 以外的依赖）：
Vue 3.4 + TS + Vite 5 + Tailwind 3.4 + Element Plus（本次 Hero 不用其表单控件）+ Pinia + Vue Router + motion-v + @vueuse/core，monorepo（pnpm）。

### 1.2 允许对上述区块做的「最小接入改动」（仅这 4 项）
1. 给 10 张矩阵卡片的根元素添加 `data-column-key="<columnKey>"` 属性。

### 1.3 导航栏 Ctrl/⌘+K
- 快捷键**只绑定导航栏搜索框**。若已存在，保持不变；若尚未实现，在导航搜索组件内用 `@vueuse/core` 的 `onKeyStroke`/`useEventListener` 实现（Ctrl/⌘+K → `preventDefault` + focus 导航搜索框）。

- 页面因此同时存在两个搜索框，这是设计预期，不要隐藏任何一个。

1. **刻度环**：两个同心椭圆（rx/ry ≈ 150/110 与 215/160），`stroke:#E2E8F0`，不透明度 .6；外环叠加一圈极细短刻度（约 72 个，长 4px，`#CBD5E1`，不透明度 .5），外环刻度整体缓慢旋转（60s 线性循环，仅 `transform`）。

### 7.3 交互状态机

**交互定义**
- **单专栏节点**（高考志愿、英语专项、大学成长）：hover 仅有 §7.2 的悬浮反馈；**点击 → 触发聚焦请求**（滚动到下方，见 §8）。
- **多专栏节点**（初高中、考研深造、考公就业）：
   - **hover**（桌面，意图延迟 150ms）→ 进入「展开预览」。
   - **click** → 「展开并固定（pinned）」，鼠标移走不再收起。
   - 触屏设备无 hover，仅 click。

**展开形态（Level 1）**，动画时长约 480ms，`cubic-bezier(0.32,0.72,0,1)`：
1. 被选中的模块节点**平滑移动到罗盘中心偏上位置 (280,210) 并放大至 1.15 倍**（同一个 DOM 元素做 transform 过渡，不要销毁重建）。
2. 其余 5 个模块节点及其连线、中心 Logo 圆盘：`opacity→0; scale→.92; pointer-events:none`（只展示这一个模块）。刻度环保持，降低到不透明度 .35。
3. 该模块的二级专栏节点从其中心位置**依次弹出（stagger 60ms，scale .6→1）**，并由 SVG 连线自该模块节点「描边绘制」到每个子节点：
   - 2 个子节点：中心 (118,340)、(442,340)
   - 3 个子节点：中心 (280,62)、(118,348)、(442,348)
4. **子节点卡**：宽 160 × 高 60，样式同模块节点卡。图标使用**该专栏在矩阵中已有的图标**（若图标支持 `currentColor`，染成该模块主色；否则原样使用），标题为专栏名（如「考研专栏」），副文案为矩阵卡片的副标题（如「择校初试与复试规划」），右侧 `ArrowDown`。**不显示数量角标。**
5. 展开形态下，左上角出现返回按钮 `ChevronLeft + 全部模块`（8px 圆角文字按钮，非胶囊），底部居中出现提示 `点击专栏，直达下方对应位置`（12px / `#64748B`）。
6. 子节点 **click → 触发聚焦请求**；hover 仅有悬浮反馈。

**收起条件**
- 未固定（hover 预览）：鼠标离开**整个罗盘容器**后 250ms 收起（以容器级 mouseleave 判断，而不是节点级，避免节点位移导致闪烁）。
- 已固定：点击返回按钮、点击罗盘空白处、按 `Esc`、再次点击中心的模块节点。
- 点击子节点触发聚焦请求后，**保持当前展开状态**，不自动收起。

**要求**
- 状态集中在 `HfHeroCompass.vue`：`activeKey: string | null`、`pinned: boolean`，用 `computed` 派生每个节点的 transform/opacity。
- 动画只用 `transform` 与 `opacity`（连线描边用 `stroke-dashoffset`）。
- 展开/收起期间防抖，避免快速进出造成状态错乱；切换中不丢事件。

## 8. Hero → 导航区块的联动

### 8.1 通道
新增 `useColumnFocus()`（模块级单例 `ref`，或 Pinia 小 store 均可）：
- Hero 调用 `requestFocus({ columnKey, color, nonce })`，`nonce` 每次递增，保证重复点击同一专栏也能再次触发。
- 「全周期生涯规划导航」区块组件 `watch` 该请求，并根据**自己当前的视图状态**分别处理。**Hero 不关心当前是矩阵还是图谱。**
- 若目标元素不存在，降级为仅滚动到该区块顶部，不报错。

### 8.2 滚动偏移
- 动态计算 sticky/fixed 导航的总高度作为偏移（不要写死数字）；统一设置 CSS 变量，如 `--hf-nav-offset`。
- 使用 `window.scrollTo({ behavior:'smooth' })`。`prefers-reduced-motion` 时使用 `behavior:'auto'`。
- 滚动结束判定：优先 `scrollend` 事件，不支持时降级为「位置稳定检测 / 700ms 超时」。**动画必须在滚动结束后再触发**，保证用户能看到。

### 8.3 矩阵视图（当前显示矩阵时）
1. 找到 `[data-column-key="<key>"]` 的卡片，滚动到使其**在可视区（扣除导航偏移后）垂直居中**。
2. 滚动结束后给该卡片加上临时类 `is-hf-pulse`，持续约 2s 后移除，可重复触发（先移除、强制 reflow、再添加）。
3. 高亮效果：
   - 图标底座做 2 次缩放脉冲（1→1.12→1），并带柔光环 `box-shadow: 0 0 0 6px rgba(var(--hf-pulse-rgb), .18)`；
   - 序号角标做一次轻弹；
   - 卡片整体上浮 2px，使用暖光阴影；
   - `--hf-pulse-rgb` 由请求中的模块主色提供。
4. **严禁使用实线彩色边框或 `border-image`**，只用 `box-shadow` / `transform`。
5. `prefers-reduced-motion`：不做脉冲，仅保持静态柔光环约 1.2s。
6. **不切换视图、不改变矩阵卡片平时的任何样式。**

### 8.4 图谱视图（当前显示图谱时）
1. **不切换到矩阵视图。**
2. 滚动使图谱画布卡片完整进入可视区（顶部贴近导航偏移下方）。
3. 调用 `selectNodeByKey(columnKey)`，效果与用户亲手点击该节点**完全一致**：选中节点、展开 ER 属性卫星、右侧面板展示该实体信息。
4. 图谱不做额外高亮或闪烁；矩阵也不做高亮。
5. 如图谱节点 ID 与 `columnKey` 不一致，建立映射表并在汇报中列出。

## 9. 背景与接缝

- 先按 §2 的调研结果判断背景所属层级：
   - 若淡网格/暖渐变是**页面级**：Hero 保持透明，让页面背景自然透出。
   - 若是**区块级**：Hero 使用同色系背景，底部必须渐变融入下方区块，不得出现可见分界线。
- Hero 自身只叠加极轻的装饰层（`pointer-events:none; aria-hidden`）：
   - 右侧一团晴空蓝径向光斑（`rgba(37,99,235,.07)`）；
   - 极淡的「节点—连线」SVG 纹理（呼应图谱视图），不透明度 ≤ .5，向下 mask 渐隐。
- 主体不使用大面积暖橙背景，卡片区保持冷灰白与纯白层次。

- 右：三组并列数字，数字 28px / 800 / `letter-spacing:-0.02em` / tabular-nums，下方 12px `#64748B` 说明：
   - `10` 大系统专栏：海枫橙 `#F97316`
   - `120+` 算法库：深曜黑 `#0F172A`
   - `200K+` 全国学子：晴空蓝 `#2563EB`

## 11. 入场动效（motion-v，一次性）

总时长 ≤ 1.2s：
1. 左栏各元素 fade-up（`opacity 0→1, translateY 12px→0`），stagger 60ms。
2. 罗盘：中心圆盘 scale-in → 6 条连线描边绘制（600ms）→ 6 个节点 stagger 70ms 弹出。
3. 看板条最后淡入。

全部尊重 `prefers-reduced-motion`（直接呈现最终态）。循环动画（刻度旋转、连线流动、呼吸点）在 Hero 滚出视口或 `document.hidden` 时暂停（`IntersectionObserver` / `animation-play-state`）。

## 12. 响应式

| 宽度 | 行为 |
|---|---|
| ≥1280 | 完整双栏，罗盘 560×440。 |
| 1024~1279 | 双栏，罗盘按容器宽度整体缩放：设计坐标系固定 560×440，外层用 `ResizeObserver` 计算 `scale = min(1, width/560)`，用 `transform: scale()` 并同步设置外层高度，**不要改各节点坐标**。 |

## 13. 无障碍与性能

- 罗盘根节点 `role="group"`，`aria-label="按需求快速定位专栏"`；所有节点为 `<button>`，有可见 `:focus-visible` 柔光环。
- 多专栏节点：`aria-expanded`、`aria-label` 如「初高中，包含初中专栏、高中专栏，按回车展开」。单专栏：「高考志愿，按回车定位到下方专栏」。
- Enter / Space = click；Esc = 收起并固定状态清除；展开时 Tab 顺序为：返回按钮 → 模块节点 → 子节点。
- 装饰元素（刻度环、连线、背景纹理）`aria-hidden="true"`。
- 动画只使用 `transform`/`opacity`；WebGL（ogl）与 Lottie **本次不使用**；Hero 不新增阻塞首屏的大体积资源。
- 搜索框与主 CTA 属于首屏关键路径，不得被懒加载。

## 14. 设计规范红线（必须遵守）

1. 橙色仅出现在：标题强调词、搜索提交按钮、主 CTA、「高考志愿」节点、看板条第一个数字，以及导航栏既有橙色。其余用冷灰/白与蓝、青、绿、黄、红分流。
2. 卡片：纯白 + 1px 发丝边 + 双层弥散阴影；严禁彩色实线外框、严禁 `border-image`。
3. 形态：全圆角胶囊只用于 CTA、分段切换器、状态胶囊；说明性标签为 6px 圆角矩形；序号/数量角标为正圆。
4. 文字色阶使用 Slate 体系；黄色文字必须 `#D97706`/`#B45309`，禁止浅亮黄。
5. 禁止 Emoji，禁止中文方括号标签。
6. 文案与数字全部配置化；不得出现 `0 个专业` 之类的渲染。
7. TypeScript 严格类型，`<script setup lang="ts">`，不得有 `any`；组件拆分合理，单文件不超过约 300 行。

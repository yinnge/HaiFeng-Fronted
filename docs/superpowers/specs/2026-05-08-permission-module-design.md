## 1. 概述

### 1.1 项目背景
海枫未来规划院管理后台的第一阶段开发，聚焦于**登录界面**和**后台管理-权限模块**。

### 1.2 开发范围

| 功能 | 阶段 | 说明 |
|------|------|------|
| 登录界面 | **第一阶段** | Tab 切换用户/管理员，验证码，TOTP 弹框 |
| 后台管理-权限模块 | **第一阶段** | 角色/模块/管理员列表 CRUD |
| 首页 | 第二阶段 | 个人中心入口 + 后台管理入口 |
| 个人中心 | 第二阶段 | 展示用户信息 + 二维码 |

### 1.3 设计风格

**混合方案**：深蓝主色 + 珊瑚色 CTA + 灰白后台

| 元素 | 颜色 |
|------|------|
| 主色（标题/链接） | `#1565c0` / `#1e88e5` |
| CTA 按钮 | `#1e88e5`（蓝色）或 `#cc785c`（珊瑚色） |
| 后台背景 | `#f0f2f5`（灰白） |
| 侧边栏 | `#001529`（深蓝黑） |
| Logo | 红黄蓝渐变枫叶 |

### 2.6 登录卡片

#### Tab 切换

| Tab | 功能 | API 前缀 |
|-----|------|----------|
| 用户登录 | 登录 + 注册 | `/api/v1/app/auth/` |

#### 用户注册表单（点击"立即注册"切换）

| 字段 | 类型 | 必填 | 说明 |

| phone | input | 是 | 手机号 |
| password | password | 是 | 密码 |
| captchaCode | input | 是 | 验证码 |
| referrerCode | input | 否 | 邀请码（选填） |

#### 管理员登录表单

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| phone | input | 是 | 手机号 |
| password | password | 是 | 密码 |

- **无邀请码字段**

### 2.7 忘记密码

- **位置**: 登录按钮上方，右对齐
- **交互**: 点击弹出浮层
- **内容**: "忘记密码请联系管理员：13303575004"
- **按钮**: "我知道了"

### 2.8 TOTP 二次验证弹窗

当管理员开启 TOTP 时，登录返回 `code=20001`，弹出验证弹窗：

| 字段 | 说明 |
|------|------|
| preAuthToken | 从登录响应获取（hidden） |
| totpCode | 6 位动态验证码 |

### 2.9 底部协议

```
登录即表示已同意《用户协议》和《隐私政策》
```

- **颜色**: 蓝色可点击（`#1e88e5`）
- **交互**: 点击弹出协议内容弹窗
- **协议内容**: 说明收集手机号和微信号用途，承诺不泄露

## 4. 权限模块列表页

### 4.1 角色列表

#### API
- 列表: `GET /api/v1/admin/permission/roles`
- 详情: `GET /api/v1/admin/permission/roles/{id}`
- 新增: `POST /api/v1/admin/permission/roles`
- 更新: `PUT /api/v1/admin/permission/roles/{id}`
- 删除: `DELETE /api/v1/admin/permission/roles/{id}`
- 切换状态: `PUT /api/v1/admin/permission/roles/{id}/toggle-status`
- 绑定模块: `POST /api/v1/admin/permission/roles/{id}/modules`

#### 搜索字段
| 字段 | 类型 | 说明 |
|------|------|------|
| roleName | 模糊搜索 | 角色名称 |
| status | 精确匹配 | 0=禁用，1=启用 |

#### 表格列
| 列名 | 字段 | 说明 |
|------|------|------|
| 角色名称 | roleName | - |
| 角色编码 | roleCode | 灰色显示 |
| 描述 | description | 灰色显示 |
| 状态 | status | Tag 标签（启用=蓝/禁用=黄） |
| 操作 | - | 详情/禁用(启用)/删除 |

### 4.2 管理员列表

#### API
- 列表: `GET /api/v1/admin/permission/admins`
- 详情: `GET /api/v1/admin/permission/admins/{id}`
- 新增: `POST /api/v1/admin/permission/admins`
- 更新: `PUT /api/v1/admin/permission/admins/{id}`
- 删除: `DELETE /api/v1/admin/permission/admins/{id}`
- 切换状态: `PUT /api/v1/admin/permission/admins/{id}/toggle-status`

#### 搜索字段
| 字段 | 类型 | 说明 |
|------|------|------|
| username | 模糊搜索 | 用户名 |
| phone | 模糊搜索 | 手机号 |
| realName | 模糊搜索 | 真实姓名 |
| status | 精确匹配 | 0=禁用，1=启用 |

#### 表格列
| 列名 | 字段 | 说明 |
|------|------|------|
| 用户名 | username | - |
| 真实姓名 | realName | - |
| 手机号 | phone | - |
| 角色 | roleName | - |
| 状态 | status | Tag 标签 |
| 操作 | - | 详情/禁用(启用)/删除 |

### 4.3 模块列表

#### API
- 列表: `GET /api/v1/admin/permission/modules`（树形，无分页）
- 新增: `POST /api/v1/admin/permission/modules`
- 更新: `PUT /api/v1/admin/permission/modules/{id}`
- 删除: `DELETE /api/v1/admin/permission/modules/{id}`
- 切换状态: `PUT /api/v1/admin/permission/modules/{id}/toggle-status`

#### 搜索字段
| 字段 | 类型 | 说明 |
|------|------|------|
| moduleCode | 精确匹配 | 模块编码 |

#### 表格列（树形展示）
| 列名 | 字段 | 说明 |
|------|------|------|
| 模块名称 | moduleName | 带缩进层级 |
| 模块编码 | moduleCode | - |
| 路由路径 | path | - |
| 图标 | icon | - |

## 5. 详情弹窗设计

### 5.1 通用规则

- **触发**: 点击表格行的"详情"按钮
- **展示**: 当前页面上叠加浮层（Modal）
- **表单**: 预填当前行数据，支持编辑
- **底部按钮**: 退出 + 保存

### 5.2 退出逻辑

```
点击"退出"
  → 检测表单是否有修改
    → 无修改：直接关闭
    → 有修改：弹出确认框
      → "取消"：返回编辑
      → "不保存退出"：关闭弹窗
      → "保存并退出"：调用更新接口后关闭
```

### 5.3 角色详情弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| roleName | input | 是 | 角色名称 |
| roleCode | input | 是 | 角色编码 |
| description | textarea | 否 | 描述 |
| moduleIds | 多选 | 否 | 绑定模块（多对多） |

### 5.4 管理员详情弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| username | input | 是 | 用户名 |
| realName | input | 否 | 真实姓名 |
| phone | input | 是 | 手机号 |
| email | input | 否 | 邮箱 |
| roleId | select | 是 | 角色（一对多） |
| status | select | 否 | 状态 |
| password | password | 否 | 重置密码（留空不修改） |

### 5.5 模块详情弹窗

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| moduleName | input | 是 | 模块名称 |
| moduleCode | input | 是 | 模块编码 |
| parentId | select | 否 | 父模块（子模块必填） |
| path | input | 否 | 路由路径 |
| icon | input | 否 | 图标 |
| sortOrder | number | 否 | 排序 |
| level | select | 是 | 层级（1=父，2=子） |
| description | textarea | 否 | 描述 |

## 7. 错误处理

### 7.1 表单验证

- 必填字段为空：红色边框 + 提示文字
- 格式错误：红色边框 + 具体错误信息

### 7.2 接口错误

| 错误码 | 处理 |
|--------|------|
| 400 | 显示 msg 内容（参数错误、重复等） |
| 401 | 跳转登录页 |
| 403 | 显示"无权限"提示 |
| 1006 | 显示"账号已锁定，请30分钟后重试" |
